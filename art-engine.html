Research

  • Research on high-concurrency AI serving infrastructure Analyzed high-density model serving architectures and GPU acceleration techniques utilizing ONNX/TensorRT optimization, Triton Inference Server, and vLLM.
  • Study on LLM Gateway and multi-tenant environments Designed integrated routing for SaaS and self-hosted models, and analyzed resource isolation and cost control strategies through token bucket algorithms and observability logging.
  • Structuring state machine-based agent pipelines Devised serving architectures to persist execution states and conversation contexts of autonomous agents in stateless backend environments using LangGraph and Redis checkpointing.
  • Evaluation of modular RAG integration and quantitative quality assessment Conceptualized platform-level RAG components and researched evaluation pipelines using RAGAS (LLM-as-a-Judge) to quantify hallucination risks and retrieval precision.
  • 대용량 트래픽 대응 AI 서빙 인프라 리서치 모델 경량화(ONNX/TensorRT)와 Triton Inference Server, vLLM 기반의 고밀도 모델 서빙 아키텍처 및 GPU 가속 기술 검토.
  • LLM 게이트웨이 및 멀티 테넌트 환경 연구 SaaS 및 자체 호스팅 모델의 통합 라우팅을 설계하고, 토큰 버킷 알고리즘 및 관측성(Observability) 로깅을 통한 부서별 자원 격리 및 비용 통제 방안 분석.
  • 상태 머신 기반 Agent 파이프라인 구조화 LangGraph와 Redis 체크포인팅을 활용하여 무상태(Stateless) 백엔드 환경에서 자율형 에이전트의 실행 상태와 대화 문맥을 영속화하는 서빙 아키텍처 도출.
  • 모듈형 RAG 통합 및 정량적 품질 평가 방안 검토 재사용 가능한 RAG 컴포넌트 플랫폼화를 구상하고, RAGAS(LLM-as-a-Judge)를 도입하여 시스템의 환각(Faithfulness) 여부 및 검색 정밀도를 수치화하는 평가 파이프라인 연구.
